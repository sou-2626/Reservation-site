【アップロード方法】

FFFTPなどで、サーバーの公開ディレクトリ（例：public_html / www）内に
「reserve_site」フォルダごとアップロードしてください。
※ dataフォルダは書き込み権限（705 または 755）を付与してください。

---

【リマインド（翌日通知）設定方法（ロリポップ）】

1: サーバーの管理・設定 → cron設定  
2: 設定名 → わかりやすいものに（例：予約の前日リマインド）  
3: 日付は「毎月・毎日・毎曜日」すべてチェック  
4: 時間は通知したい時間（例: 8時30分）  
5: 実行ファイル → reserve_site/send_reminder.php  
6: 一番下の設定ボタンを押す  

これで「処理は正常に終了しました。」と表示されれば完了です。

※ このスクリプトは、翌日の予約内容を「管理者メールアドレス」に通知します。  
　送信先は、管理画面の「管理者メール設定」で登録されたメールです。

---

【トラブル時の確認】

・「DB接続エラー」と出る場合 → reserve_site/data/ の書き込み権限を確認してください。  
・「未対応のアクションです」と出る場合 → ファイルが正しくアップロードされたか確認してください。
